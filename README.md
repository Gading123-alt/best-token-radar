Token Radar ranks every pre-token protocol in the sealed DefiLlama snapshot — all 40 watchlist protocols plus the 249 pre-token protocols below the floor — by an implied launch value built from TVL, 7-day growth, age and chain breadth, and gives each one a concrete 7-step farm plan with costs and times on a dark, offline dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
